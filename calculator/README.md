# Everyday Calculator

A Python desktop calculator with arithmetic, linear and quadratic equation solving, plus currency, mass, gravity / acceleration, and data size converters.

## Run

Install Python 3.10 or later and run `python app.py` from this folder. The app uses Tkinter from the Python standard library.

Currency conversion starts with illustrative rates. Use **Refresh rates online** to load current rates; internet access is required. Other converters work offline.
